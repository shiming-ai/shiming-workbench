共创伙伴合作协议

版本：V1.0 · 生效日期：签署之日
甲方：Crazy Friday 疯狂星期五（以下简称"甲方"）
乙方：合伙人姓名（以下简称"乙方"）
一、合作背景与目的

甲方是一套真实在运营的AI商业系统，拥有6条业务线、工作台系统、课程体系等完整资产。

甲方开放共创伙伴计划，乙方申请加入，双方本着平等自愿、互利共赢的原则，达成如下协议。

二、合伙人角色与权益

乙方选择以下角色（勾选一项）：

  • □ 渠道合伙人：负责获客引流，推荐客户成交拿20-30%分成。入驻费¥990。
  • □ 交付合伙人：负责AI定制项目交付，按项目结算60-70%。入驻费¥2900。
  • □ 城市合伙人：区域/行业独占，全业务线35-45%分成。入驻费¥6900。

入驻费性质：预付合作金，非加盟费。渠道可抵扣前4单分成；交付含技术模板库；城市含品牌授权+区域保护。

三、报名与审核

1. 乙方先支付¥299报名审核费，填写优势资源说明。

2. 甲方创始人在3个工作日内安排1v1沟通，确认合作方向。

3. 沟通后双方决定合作，乙方补齐入驻费差额（299可抵扣）。

4. 如沟通后任一方认为不合适，299全额退还乙方。

四、独立工作台与数据归属

1. 甲方为乙方开通独立工作台子账号，包含客户管理、订单追踪、收益看板等功能。

2. 乙方工作台数据与其他合伙人完全隔离，互不可见。

3. 数据归属：乙方在工作台产生的所有客户数据、订单数据、交易数据，归属甲方所有。乙方仅有使用权，无所有权。

4. 甲方总后台可查看所有合伙人的数据汇总，用于全局管理和结算。乙方仅可查看自身数据。

5. 退出机制：乙方退出后，甲方回收工作台账号。客户数据留存甲方，乙方不得带走或泄露。

五、保密条款

乙方对以下信息负有保密义务，不得向第三方泄露：

  • 甲方的技术架构、代码、系统设计
  • 甲方的客户名单、定价体系、分成比例
  • 其他合伙人的身份和数据
  • 甲方未公开的业务计划、项目信息

保密期限：合作期间及合作终止后3年内。违反者甲方有权清退并追偿损失。

六、报价与结算

1. 乙方必须使用甲方系统内的专属报价体系，不得私下加价或降价。

2. 所有客户款项统一打入甲方账户，甲方在T+3个工作日内按分成比例结算给乙方。

3. 乙方不得绕过甲方私下与客户交易，一经发现立即清退，入驻费不退。

4. 结算方式：微信/支付宝/银行转账，乙方提供收款账户信息。

七、违规处理

乙方如有以下行为，甲方有权按程度处理：

  • 轻度违规（如未按时提交数据）：警告+扣减当月分成10%
  • 中度违规（如私下报价、私自联系其他合伙人客户）：暂停账号7天+扣减当月分成30%
  • 严重违规（如私下交易、泄露数据、损害品牌）：立即清退+入驻费不退+追究法律责任
八、合作期限与退出

1. 合作期限：签署之日起1年有效，到期可续签。

2. 乙方提前30天书面通知可主动退出，已完成订单正常结算。

3. 甲方如认为乙方不适合继续合作，提前15天通知可终止协议，入驻费按比例退还。

4. 城市合伙人退出后，区域独占保护取消，甲方可另行招募。

九、其他条款

1. 本协议电子签署，与纸质协议具有同等法律效力。

2. 双方因履行本协议发生争议，友好协商解决；协商不成的，提交甲方所在地人民法院诉讼解决。

3. 甲方保留对本协议的最终解释权。

4. 协议更新时，甲方提前7天通知乙方，乙方可选择接受或退出。
